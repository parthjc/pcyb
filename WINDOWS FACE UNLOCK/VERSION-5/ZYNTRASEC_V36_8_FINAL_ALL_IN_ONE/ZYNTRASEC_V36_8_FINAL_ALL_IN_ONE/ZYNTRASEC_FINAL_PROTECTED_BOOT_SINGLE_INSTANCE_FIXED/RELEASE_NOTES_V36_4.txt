ZYNTRASEC V36.4 - CreateProcessAsUser SECURITY_ATTRIBUTES FIX

Fixes the V36.3 regression where CreateProcessAsUser raised:
"TypeError: The object is not a PySECURITY_ATTRIBUTES object"

Root cause: V36.3 passed win32security.SECURITY_ATTRIBUTES() objects to
CreateProcessAsUser. V36.4 uses None for both optional process/thread
SECURITY_ATTRIBUTES parameters, which is supported by pywin32.

Retains the V36.2 DuplicateTokenEx integer-argument fix.
